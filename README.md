# ⚡ منصة زلزال نيون التكنولوجية (Zelzal Cyber Platform 2.0)

منصة وتطبيق ويب سيبراني حديث وعصري بنظام نيون فائق التطور مستوحى من منصة زلزال، مصمم بالكامل للعمل باللغة العربية (RTL) مع مؤثرات بصرية وصوتية تفاعلية.

---

## 🌟 الميزات الرئيسية المكتملة

### 1. نظام المصادقة والحساب (Authentication & Mandatory ID)
- **إنشاء حساب جديد**: (الاسم، البريد الإلكتروني، رقم الهاتف، كلمة المرور، تأكيد كلمة المرور، و **معرف ID إجباري وفريد** مثل `ID-84920`).
- **تسجيل الدخول**: الدخول إما عبر **البريد الإلكتروني أو معرف الـ ID** + كلمة المرور.
- **تبويب حسابي (على اليسار)**: عرض وتعديل الصورة الشخصية، الـ ID مع زر نسخ سريع، الاسم، البريد، رقم الهاتف، وكلمة المرور.

### 2. نظام الرومات الصوتية (Cyber Voice Rooms & Live Stage)
- استعراض وبحث الرومات المتاحة.
- **إنشاء روم جديدة**: يشترط توفر **500 نقطة** ليتم خصمها تلقائياً عند الإنشاء مع رفع اسم وصورة ونبذة وقفل اختياري.
- **منصة البث المباشر (Stage)**: 8 مقاعد للمتحدثين مع هالة صوتية تفاعلية وشات مباشر وتفاعلات نيون.
- **لوحة تحكم المالك والمشرفين**:
  - 👑 **رفع إشراف** للأعضاء المتحدثين.
  - 🚫 **طرد** المستخدمين من الروم.
  - 🔒 **حظر نهائي** من الدخول.
  - 🔑 **قفل الروم برمز سري (Passcode PIN)**.

### 3. عداد الفراشة النيون 24 ساعة (24H Butterfly Spinning Counter)
- **شريط إعلاني تكنولوجي متحرك (Neon Ticker)** في الأعلى.
- **فراشة نيون ثلاثية الأبعاد تفاعلية** داخل دوائر سيبرانية متوهجة.
- عند الضغط على "فر الفراشة": تبدأ بالدوران التكنولوجي السلس وتبدأ عداد **24 ساعة متواصلة**.
- **العداد المجاني اليومي**: يمنح **50 نقطة مجانية يومياً** مع مؤقت تنازلي.
- **عداد الشراء**: يبدأ من 0 ويعرض العدادات المشتراة والأرباح التراكمية مع زر جمع الأرباح.

### 4. متجر العدادات (Cyber Store)
- شراء العدادات التوربو:
  - ⚡ **عداد 500 نقطة**: ينتج +35 نقطة/يومياً.
  - 🔮 **عداد 1000 نقطة**: ينتج +80 نقطة/يومياً.
  - 🔥 **عداد 1500 نقطة**: ينتج +140 نقطة/يومياً.
  - 👑 **عداد 2000 نقطة**: ينتج +220 نقطة/يومياً.
- زر شحن نقاط تجريبية فوري لاختبار الشراء وإنشاء الرومات.

### 5. نظام الدعم الفني الذكي (Support Hub & AI FAQ Bot)
- **مراسلة الفريق المختص**: إرسال تذاكر دعم فني ومتابعة الردود الفورية من المشرفين.
- **بوت الأسئلة الشائعة**: شات بوت ذكي مبرمج للرد على كافة استفسارات المنصة مع أزرار اقتراحات سريعة.

## ☁️ الربط مع Supabase (Supabase Integration)

1. افتح حسابك في [Supabase](https://supabase.com) وأنشئ مشروعاً جديداً.
2. توجه إلى **SQL Editor** وانسخ محتوى ملف `database/supabase_schema.sql` وقم بتنفيذه.
3. افتح المنصة واضغط على زر **Supabase ☁️** أعلى الشاشة، ثم أدخل:
   - `Project URL`
   - `Anon Public API Key`
4. ستتم مزامنة بيانات الحسابات والرومات والعدادات سحابياً بشكل تلقائي ومباشر!
